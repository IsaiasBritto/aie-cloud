# figuras/ — geradores das figuras do deck (versão Azure)

`render_deva3.py` e `deck3.js` geraram as figuras do Deva3 para o deck da versão
**Azure** (Image Analysis, Face, Blob, Container Apps). Ficam aqui só como
referência histórica: **não descrevem a versão AWS** deste laboratório.

Para os desenhos atuais, use os diagramas Mermaid de `docs/diagramas/` (e os PNG em
`docs/imagens/`), que já refletem Rekognition, S3 e ECS Fargate.
